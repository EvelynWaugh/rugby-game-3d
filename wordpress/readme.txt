FPV rugby-drone game built with React Three Fiber.

== Description ==

Install the plugin, create a page, and put the `[rugby_game]` shortcode on it. That page becomes the game.

== Installation ==

1. Upload the zip in Plugins → Add New → Upload Plugin.
2. Activate Sky Sovereign 3D.
3. Add a page whose content is `[rugby_game]`.
4. Open that page.
